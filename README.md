# CardThings

A card-based website for organizing and showcasing collections.

CardThings presents collection items as cards, providing a clear, flexible way to browse and highlight curated content.

## Preview the collection

The experimental frontend uses React, TypeScript, and Vite. It includes an explicitly labeled example collection with search, categories, sorting, favorites, and item details.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` to create a static `dist/` directory, or `npm run preview` to inspect that build locally.

See [development and content guide](docs/development.md) for customization, testing, and current scope, and [asset notes](docs/assets.md) for the sample imagery.
